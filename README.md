# Biometrics-Backend

Employee Attendance Management System — Node/Express/PostgreSQL backend and React/Vite frontend.

## Project Structure

## Tech Stack

**Backend:** Node.js, Express, PostgreSQL, JWT, bcrypt

**Frontend:** Vite, React 19, TypeScript 6, Tailwind CSS 3, react-hook-form, Zod, framer-motion

## Getting Started

### Backend

```bash
cd backend
npm install
npm run dev
```

Runs on `http://localhost:5000`

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Runs on `http://localhost:5173`

## Backend Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start server with nodemon (auto-restart) |
| `npm start` | Start server |

## Frontend Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start dev server |
| `npm run build` | TypeScript check + Vite build |
| `npm run preview` | Preview production build |
| `npm run lint` | Run Oxlint |
